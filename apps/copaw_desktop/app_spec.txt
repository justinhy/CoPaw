## Component Specifications

### 1. CoPaw Integration Layer (Server-Side)

**Component**: `DesktopChannel` (in CoPaw core)
**Location**: `copaw/app/channels/desktop/`
**Parent Class**: `BaseChannel`

**Responsibilities**:
- Expose WebSocket endpoint at `ws://host:port/ws/desktop`
- Convert incoming JSON messages to `AgentRequest`
- Stream agent responses back to client
- Support widget actions (images, charts, markdown) in response payload

**Protocol**:

Client → Server (Text Message):
```json
{
  "type": "text",
  "content": "用户输入的文本",
  "session_id": "uuid-string"
}
```

Server → Client (Streaming Response):
```json
{
  "type": "text_chunk",
  "content": "部分文本",
  "is_final": false
}
```

```json
{
  "type": "widget",
  "widget_type": "image",
  "data": {
    "url": "https://example.com/image.png"
  }
}
```

```json
{
  "type": "widget",
  "widget_type": "chart",
  "data": {
    "option": {"xAxis": {...}, "series": [...]}
  }
}
```

### 2. Core Engine Components (Client-Side)

#### 2.1 Network Layer (`core/network.py`)

**Class**: `WebSocketClient`

**Key Methods**:
- `connect(url: str) -> bool`: Establish connection with retry logic
- `send(message: dict) -> None`: Queue message for sending
- `disconnect() -> None`: Graceful shutdown
- `on_message(callback: Callable) -> None`: Register message handler

**State Machine**:
- `DISCONNECTED` → `CONNECTING` → `CONNECTED` → `DISCONNECTED`
- Auto-reconnect with exponential backoff (1s, 2s, 4s, max 30s)

#### 2.2 Audio Pipeline (`core/audio.py`)

**Class**: `AudioRecorder` (runs in QThread)

**Key Features**:
- Continuous microphone capture using PyAudio
- VAD integration (Silero VAD preferred)
- Automatic sentence segmentation on 1.5s silence
- Mute control for TTS playback (echo prevention)

**Signals**:
- `audio_chunk_ready(bytes)`: Emitted when complete sentence detected
- `recording_started()`: VAD detected speech start
- `recording_stopped()`: VAD detected silence

#### 2.3 Cloud Services (`core/asr.py`, `core/tts.py`)

**ASR Client Interface**:
```python
class ASRClient(ABC):
    @abstractmethod
    async def transcribe(self, audio_bytes: bytes) -> str:
        pass
```

**Recommended Implementation**: Alibaba Cloud ASR (DashScope) or OpenAI Whisper API

**TTS Client Interface**:
```python
class TTSClient(ABC):
    @abstractmethod
    async def synthesize(self, text: str, voice: str = "default") -> bytes:
        pass
```

**Recommended Implementation**: edge-tts (Microsoft Edge TTS, free and high quality)

#### 2.4 Data Layer (`core/models.py`, `core/database.py`)

**SQLAlchemy Models**:

```python
class Session(Base):
    __tablename__ = "sessions"
    id = Column(String, primary_key=True)
    started_at = Column(DateTime, default=datetime.utcnow)
    title = Column(String, nullable=True)
    messages = relationship("Message", back_populates="session")

class Message(Base):
    __tablename__ = "messages"
    id = Column(String, primary_key=True)
    session_id = Column(String, ForeignKey("sessions.id"))
    role = Column(String)  # "user" or "assistant"
    content = Column(Text)
    created_at = Column(DateTime, default=datetime.utcnow)
    widget_data = Column(JSON, nullable=True)  # For images/charts
    session = relationship("Session", back_populates="messages")
```

**SessionDB Methods**:
- `create_session() -> Session`
- `get_sessions_grouped_by_hour() -> Dict[date, Dict[hour, List[Session]]]`
- `add_message(session_id, role, content, widget_data=None) -> Message`
- `get_messages(session_id) -> List[Message]`

### 3. GUI Layer Components

**Layout**:

**Fullscreen Behavior**:
- Call `showFullScreen()` on startup
- Support `F11` or `Esc` to toggle (configurable)
- Hide menu bar and status bar in fullscreen mode

#### 3.2 Left Panel - Session List (`gui/widgets/session_list.py`)

**Widget**: `QTreeWidget`

**Hierarchy**:
```

│   │   ├── Session 1 (14:23)
│   │   └── Session 2 (14:45)

```

**Behavior**:
- Click on session → Load messages in ChatPanel
- Auto-refresh when new session created
- Scroll to latest session

#### 3.3 Middle Panel - Chat Panel (`gui/widgets/chat_panel.py`)

**Widget**: `QScrollArea` with `QVBoxLayout`

**Message Bubble Styles**:
- User: Right-aligned, blue background
- Assistant: Left-aligned, gray background
- Markdown support for code blocks and formatting

**Streaming Behavior**:
- Append text chunks character by character
- Smooth scroll to bottom on new content
- "Typing indicator" when waiting for response

#### 3.4 Right Panel - Dynamic Panel (`gui/widgets/dynamic_panel.py`)

**Widget**: `QStackedWidget` with switchable sub-widgets

**Sub-Widgets**:
1. **EmptyStateWidget**: Default logo or instructions
2. **ImagePreviewWidget**: `QLabel` with `QPixmap`, supports zoom
3. **MarkdownPreviewWidget**: `QWebEngineView` rendering markdown
4. **ChartWidget**: `QWebEngineView` with ECharts

### 4. State Management

**Application States**:
```python
class AppState(Enum):
    IDLE = "idle"                    # Waiting for user input
    LISTENING = "listening"          # Microphone active, VAD monitoring
    PROCESSING = "processing"        # ASR + CoPaw processing
    SPEAKING = "speaking"            # TTS playback, mic muted
```

**State Transitions**:
- `IDLE` → `LISTENING`: User starts speaking (VAD trigger)
- `LISTENING` → `PROCESSING`: User stops speaking (1.5s silence)
- `PROCESSING` → `SPEAKING`: CoPaw response received, TTS starts
- `SPEAKING` → `IDLE`: TTS playback finished

## Testing Strategy (TDD)

### Test Categories

1. **Unit Tests** (`tests/unit/`)
   - Database operations
   - ASR/TTS clients (with mocking)
   - WebSocket client logic
   - State machine transitions

2. **Integration Tests** (`tests/integration/`)
   - Audio → ASR → WebSocket pipeline
   - WebSocket → UI rendering
   - Full message flow with mock CoPaw server

3. **GUI Tests** (`tests/gui/`)
   - Use `pytest-qt` for widget testing
   - Verify layout, signals, and user interactions
   - Screenshot comparison for visual regression

### Test-First Development Rule
**For each feature**:
1. Write failing test case first
2. Implement minimal code to pass test
3. Refactor while keeping tests green
4. Only then mark feature as `passes: true` in feature_list.json

## Deployment & Packaging

### Development Environment
```bash
# Clone and setup
git clone https://github.com/agentscope-ai/CoPaw.git
cd CoPaw/apps/copaw_desktop
./init.sh

# Run tests
pytest tests/

# Run application
python main.py
```

### Production Packaging (PyInstaller)

**Ubuntu**:
```bash
pyinstaller --onefile --windowed --name "CoPaw Desktop" main.py
# Output: dist/CoPaw Desktop
```

**Windows**:
```bash
pyinstaller --onefile --windowed --name "CoPaw Desktop.exe" main.py
# Output: dist/CoPaw Desktop.exe
```

### Platform-Specific Notes

**Ubuntu**:
- Install `portaudio19-dev` for PyAudio: `sudo apt-get install portaudio19-dev`
- PulseAudio or PipeWire for audio system
- X11 or Wayland display server support

**Windows**:
- PyAudio binary wheels available (no compilation needed)
- DirectX for audio playback
- Test on both Windows 10 and 11
